如何体验项目

按四步走完一笔安全退款

创建工单后，先由领域服务生成退款草稿，再以审批角色确认，最后由系统角色模拟执行。每一步都调用现有 API，因此都会经过权限、状态与幂等校验。

当前固定使用合成订单 ORD-1001。生产环境还需要接入真实认证、数据库与支付适配器。
